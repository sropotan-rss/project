# Competitor Monitor Bot

Telegram-бот для мониторинга конкурентов:

- **Цены и наличие на сайте** — периодически проверяет цену/текст в заданном
  месте страницы (по CSS-селектору) и уведомляет при изменении.
- **Упоминания в интернете** — отслеживает новые публикации по бренду/ключевому
  слову через Google News RSS и уведомляет о новых находках.

Проверка идёт по расписанию (интервал задаётся переменной окружения) плюс
по команде `/check_now` вручную. Все конкуренты и параметры настраиваются
прямо в чате с ботом, отдельно для каждого чата.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# впишите в .env токен бота, полученный у @BotFather
python bot.py
```

## Переменные окружения

| Переменная            | Обязательна | Описание                                   |
|------------------------|:-----------:|---------------------------------------------|
| `BOT_TOKEN`             | да          | Токен Telegram-бота от @BotFather            |
| `CHECK_INTERVAL_HOURS`  | нет         | Интервал автопроверки в часах (по умолчанию 24) |
| `DB_PATH`               | нет         | Путь к файлу SQLite (по умолчанию `monitor.db`) |

## Команды бота

- `/start`, `/help` — справка
- `/add_price Название | https://site.ru/product | .price-selector` — добавить
  отслеживание цены. CSS-селектор указывает, где на странице искать цену
  (например `.price`, `#price`, `span.product-price`).
- `/add_mention Название конкурента` — начать отслеживать упоминания бренда
  в новостях
- `/list` — список всех отслеживаний в текущем чате
- `/remove_price <id>` — удалить отслеживание цены
- `/remove_mention <id>` — удалить отслеживание упоминаний
- `/check_now` — проверить всё сразу, не дожидаясь расписания

## Как это устроено

- `bot.py` — обработчики команд и планировщик (`JobQueue` из
  `python-telegram-bot`)
- `db.py` — хранение конкурентов/параметров в SQLite
- `monitors/price.py` — загрузка страницы и извлечение цены по CSS-селектору
  (`requests` + `BeautifulSoup`)
- `monitors/mentions.py` — поиск упоминаний через Google News RSS
  (`feedparser`)
- `checks.py` — логика сравнения текущих данных с сохранёнными и отправки
  уведомлений

При добавлении отслеживания сразу делается первый запрос — он служит точкой
отсчёта, поэтому уведомления приходят только о последующих изменениях/новых
публикациях, а не обо всём, что уже было на момент добавления.
