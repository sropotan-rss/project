# Cover Letter Bot

Telegram-бот, который пишет сопроводительное письмо под конкретную вакансию
на основе твоего резюме:

1. Присылаешь резюме в PDF
2. Присылаешь ссылку на вакансию hh.ru (например `https://hh.ru/vacancy/12345678`)
3. Бот получает текст вакансии через API hh.ru и генерирует письмо, опираясь
   только на то, что реально есть в резюме

Резюме сохраняется на диске (SQLite) и используется для всех следующих
вакансий, пока не пришлёшь новый PDF.

Письмо генерируется через локально установленный **Claude Code CLI**
(`claude -p`), а не через платный Anthropic API — токены расходуются в рамках
твоей подписки Claude (Pro/Max), отдельного API-ключа не требуется.

## Предварительно: установи Claude Code CLI

```bash
npm install -g @anthropic-ai/claude-code
claude
```
Второй командой один раз войдёшь в аккаунт через браузер (нужна подписка
Claude с достаточным лимитом). После этого можно закрыть терминал — бот сам
будет обращаться к `claude` при каждом письме.

## Быстрый запуск (двойной клик)

- **Windows** — `run_bot.bat`
- **macOS** — `run_bot.command`

При первом запуске скрипт проверит наличие `claude` в PATH, создаст
виртуальное окружение, поставит зависимости и откроет `.env` для ввода
токена бота — впиши его, сохрани файл и запусти скрипт ещё раз. Дальше —
просто двойной клик, когда нужен бот; закрыть окно = остановить.

## Установка вручную

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# впиши в .env BOT_TOKEN
python bot.py
```

## Переменные окружения

| Переменная  | Обязательна | Описание                                                             |
|--------------|:-----------:|------------------------------------------------------------------------|
| `BOT_TOKEN`  | да          | Токен Telegram-бота от @BotFather (нужен отдельный от других ботов)     |
| `DB_PATH`    | нет         | Путь к файлу SQLite (по умолчанию `cover_letters.db`)                   |

## Команды бота

- `/start`, `/help` — справка
- Документ PDF — загрузить/обновить резюме
- Текст со ссылкой на hh.ru — сгенерировать сопроводительное письмо под эту
  вакансию

## Как это устроено

- `bot.py` — обработчики Telegram-сообщений
- `resume_reader.py` — извлечение текста из PDF (`pypdf`)
- `vacancy_parser.py` — получение вакансии через официальный API hh.ru
  (`api.hh.ru/vacancies/{id}`), без хрупкого скрапинга HTML
- `cover_letter.py` — генерация письма через `subprocess`-вызов Claude Code
  CLI (`claude -p`)
- `db.py` — хранение последнего резюме на чат в SQLite
